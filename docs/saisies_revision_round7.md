# Saisies 第七輪：先重建完整 S01 街景

日期：2026-10-17。root 分析與圖像驗收，Luna 實作。基準為 `export/saisies/review/all18_v7/`，本輪不覆寫基準、不修改原片與原驗收描述。原片 5 秒的精確參考為 `video/saisies_analysis/acceptance/S01_f000120.png`；0 秒 `video/saisies_analysis/storyboard/t0000.jpg` 僅補充完整餐廳形狀。

## 要重建的視覺內容

這是一條密集的山村商業街，鏡頭沿下坡向前。左側近景是米白色雙層餐廳：寬木山牆朝向街道、木陽台欄板、兩層深色招牌、米白店棚、棚下服飾店與開口。餐廳後方立即露出深灰綠色多層旅館，屋頂很淺，街側有連續堆疊陽台。右側是灰色細格金屬屋頂的深木屋，屋簷有細密垂飾，前方有旗桿與花槽。兩棟大建築之間的下坡街道繼續通過多棟灰白屋頂小屋；左側有抬高草地與石牆。遠方是寬而連續的深綠森林山脊，山面有少量淺色草甸，不是灰色裸岩尖峰。右側路緣有數個堆疊圓木式護欄／花槽，粉紅花叢溢出木箱。人物、車輛及自行車不建。

## 工作包與檔案所有權

1. **Village Luna**：`scripts/saisies_village.gd`、`tools/verify_saisies_village.gd`。負責餐廳、旅館、右木屋、中景村屋、相應鋪面；移除 S01 的鮮綠球花槽及與新路緣花槽重疊的舊 props。不得修改新 props 模組。房屋內外幾何完整，屋頂接合，煙囪與基座實際接地。
2. **Landscape Luna**：`scripts/saisies_landscape.gd`、`tools/verify_saisies_landscape.gd`。只修 S01 可見遠方山脊及森林／草甸層次。不得改 route、camera、trees。保留全線保護走廊、朝上法線及 S05/S08/S09 安全檢查，不能再次製造近景山牆。
3. **Props Luna**：新增 `scripts/saisies_village_props.gd`、`tools/verify_saisies_village_props.gd`，以及僅在 `scenes/MainScene_saisies_v2.tscn` 註冊新模組。負責右側圓木／粉花花槽、旗桿旗面；不碰村屋腳本。新模組自動查找 Route，採真實世界幾何，無人物／車、無照片貼面；避免高面數球形堆疊。

共用工作區，不得覆寫別人的變更。route、既有 FOV 與 pitch 本輪鎖定；相機例外修正見下節。新增節點須在 bake 中保留。不可把 count/metadata 或變更驗收文字當作視覺通過。

## 原生診斷後的相機修正

root 在未修改正式檔案的 v7 隔離快照測試了兩張圖：`round7_brief/yaw20.png`、`round7_brief/yaw20_right17.png`。只加 yaw 使街道開口與右木屋向原片靠近，但路緣仍過寬；再移到右側1.7m，同時改善左右路緣及建築投影。這比把所有房屋個別移動更能解釋共同誤差。

因此追加給 Props/Camera Luna：擁有 `scripts/saisies_camera.gd`、`data/saisies_scene_map.json`、`tools/verify_saisies_camera.gd`。S01 yaw 由7°改20°，新增可選的 `acceptance_lateral_m=-1.7`（正左負右，其他錨點預設0）；正常巡覽同樣沿18個錨點插值，視高／roll／其他17個靜態姿態維持原值，ground_y 依實際橫向位置求得。這仍是人工估算，未完成精密標定。建築與 props 依此新基準配置，不再為舊鏡頭偏差大幅平移。

另有原片標註副本 `export/saisies/review/round7_brief/S01_targets.png`；所有矩形為手工可見區域估計，原圖未變。

路緣抽樣診斷另存 `round7_brief/curb_diagnostic.json`：八個手工可見路緣取樣，在同 y 投影 x 的平均絕對差由約213px降至96px。它只支持先修共同視點的決策，手工讀點、估算路線、原片鏡頭畸變均未標定，不能當整體影片相似度或通過門檻；剩餘路緣誤差仍須保留。

## 交付與驗收

各 Luna 先看原片和 v7 S01，回報將修的前三個差異，再開工。各自做帶唯一 `/tmp/*.log` 的 headless 檢查並掃描完整日誌；既有 macOS CA 警告獨立列出。完成後 READY/HOLD，由 root 統一凍結並串行執行原生 Metal 截圖。

第一關是 S01 原片／v7／本輪三欄圖，逐一檢查上表；第二關為 S02、S03 及 S05/S08/S09 回歸。至少先看到整體街景的明確改善，再考慮全18幀。技術通過與視覺通過分開報告，不用全畫面像素差當影片相似度。

## 第一張街景驗收（round7_street_01）

凍結 v7 地景、整合新村屋／props／相機後完成 S01 原生截圖，無 runtime 錯誤。旅館的尖塔感消除、連續陽台與中景房屋增加；街景尚未通過。

具體退修：近花槽實際長度約5m，跨出右側畫面；花仍為少量粗莖與葉球，木頭太橘。改以約1.8–2m真實花箱、多個數公分扁葉與粉花瓣覆蓋箱口，近距沿路排列，由透視自然縮小。餐廳雙招牌都設在棚線附近，淺字疊淺牌且被深棚遮住；要求分到陽台／山牆下部及棚上方，增加對比和棚下服飾展示。以上以實際圖片判定，不沿用 count 通過作結論。

建築 code review 另發現中心 anchor 高度測試不足，已修為實際基座四角與四邊中點的坡面接地檢查，基座向下延伸，主體／屋頂不移動；新增屋頂封口。

## 遠山首版退修（round7_integrated_01）

S01/S05 原生截圖無 runtime 錯誤，八項 headless 檢查通過，但地景整合版拒收、未烘焙。S01 新山體是灰色孤丘，沒有寬緩林山輪廓；S05 新增大山且底部透出天空。全路線 corridor 通過並不能證明地景視覺正確或山腳封合。

退修方向：VillageRidge 專屬造型／材質，山稜寬緩而非單一高斯峰；目前約6km距離的全局霧會嚴重沖淡森林色，須用合理位置或專屬大氣材質處理。不能關掉全局霧來影響所有視點，不可用 camera 切換可見性。山體底部須實際接地或封合，並重新檢查 S05/S08/S09，若不成立就撤回該地景變更，保留街景已確認的改善。

第二版 `round7_landscape_02` 原生 S01/S05 也退修：色彩變綠但山體像光滑懸崖，冠層是少數巨大三角形，部分漂浮，S05 的綠色山頂與灰底斷開。原生顏色、尺度與接合缺陷不能用 headless face/normal 數量證明通過。

root 另以固定相機 ray 診斷近山位置：800–2000m 深度，原片投影 x1140–1200 的山稜會接近估算路線 s960/1410/1910/2370（水平距離約6–54m），顯示近移完整山脊與現有估算路線有實際衝突；證據為 `round7_brief/hill_route_conflict.json`，不是 GPS 測量。最後候選將保留世界固定位置，改成實際8–18m森林代理及深灰綠色，移除巨大三角冠，仍須 S01/S05 原生審查；無法成立就撤回。

## 本輪實際保留與最終檢查

最終來源為 `round7_retained`：保留村屋、店面、路緣props及S01估算視點；地景三個候選均未通過，已由Luna將landscape及其verifier逐位元還原v7，新增forest shader移除。最終候選／所有中間原生圖片仍保留，並未用退修圖替換原片。

花葉最後兩項實錯由原生圖定位：UV錯誤翻轉到木枝，導致粉花變金色細條；缺normal/tangent使normal atlas無有效基底。修正後以原圖像素取樣驗證綠葉／粉花區，加入實際normal/tangent檢查。葉冠原先只分布在頂部薄層而漂浮，改填滿土壤到頂部的半橢圓體。最終粉花／葉冠已實際可見且接近箱口，仍不代表本幀整體通過。

實際完成：6/6原生截圖、8/8 headless來源檢查，主代理逐張審查S01/S02/S03/S05/S08/S09對照；六張完整單幀通過數為0。系統CA錯誤在各log獨立記錄。沒有新增全18幀、完整巡覽效能或烘焙成功宣稱；既有烘焙檔維持all18_v7。

下一階段優先事項是街道／鏡頭與固定地形的幾何一致性，以及餐廳完整房型、連續村屋和真正的林山素材／造型；不能繼續用窗框或植物count抵銷大尺度差異。近移山脊與估算route的交叉位置已有診斷證據，須先解決此矛盾再擴展全線遠山。
