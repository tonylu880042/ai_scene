# S03 左側林緣樹形與密度

root分析／原生驗收、Luna實作。原片frame1798、PTS1799798/24000（74.991583秒），固定station930m、FOV77°、1920×1080。僅改善左坡林緣；約80%為工作目標，沒有計算或宣稱相似度分數。

舊灰色球冠牆來自S01遠景closed crowns在S03近視角被放大，下面的World/Forest則較稀疏。局部替換S01冠層bounds x142–258／z−1555–−1165的630個樹冠，其餘3373個保留在filtered MultiMesh副本，原生逐一核對transform完全相同。另處理五個左坡World/Forest chunks，最終以6個MultiMesh呈現1214棵新樹，增加尖頂、高矮、間隙與低緣闊葉層次，前緣36棵針葉中12棵轉為較低闊葉。使用既有tree factory，複製本地材質、關閉葉片fog與反光、加少量綠色emission；其他景物與光照不改。

第一批中斷前候選未固定來源，保留為工作過程；後續發現整個舊冠MM被隱藏，已修為局部篩選保留。固定候選又發現AABB中心貼地無法保證坡面根部接觸：原生72個被indices引用的木質最低點曾浮出最高0.992m。最終按surface0最低帶四個XZ端點與完整basis採樣地面，只向下修正浮根。原生再抽72點為埋入0.04–2.507m，沒有正clearance；模組全件採樣紀錄的最大埋深5.626m。部分基部深埋是本輪取捨，不能稱為所有樹根恰好貼地。

299個固定來源與6個關鍵資產雜湊確認，R22既有294個來源未改；另在交付時保存42個既有樹木模型／材質來源檔雜湊，該補充紀錄未加入既有launcher的6資產驗證。原生1214個新樹instance全部finite、位置與records誤差0、世界垂直誤差0；3373個保留冠層transform與原始GPU資料誤差0。完成主圖、真實2m側移、林緣近景及S01/S02回歸，四份日誌無錯誤／警告。

修改在距S03相機中心420m內啟用；S03截圖啟用、S01/S02截圖均停用並恢復舊表現。S01回歸逐像素相同；S02有808/2073600像素（0.039%）遠處地面／石塊邊緣微差，最大通道差7/255，檢視無明顯房屋或構圖退步，原因未單獨定位。未測連續巡覽的距離切換、全程巡覽、載入時間或FPS。

改善保留，完整S03未通過。左林仍比原片偏密、偏暗、針葉比例較高，林緣位置與輪廓有差異；近景可見範圍外保留的遠景球冠。下一項只處理路口圓形白色標線。
