# Saisies 逐幀比對與場景重建計畫

建立：2026-10-16；更新：2026-10-17。已建立 18 個代表視點的原片／Godot 固定截圖配對與審查紀錄；尚未完成全片 22,058 幀的自動逐幀對位，也尚未完成相機標定或視覺還原驗收。最新證據見 [視覺驗收紀錄](saisies_visual_acceptance.md)。

## 判斷與範圍

可以逐幀比對，但必須先建立同一位置、同一視線、同一鏡頭參數的配對。只將兩段影片同時播放，或直接比較像素差，無法判定場景內容是否一致。

原片視訊軌：1920×1080、24000/1001 fps、22,058 幀，視訊長度約 920.002 秒；整個媒體容器約 920.067 秒。後續依實際解碼影格的 PTS／時間戳配對，不將容器長度或四捨五入 24 fps 當作逐幀索引依據。

持續遵守純環境範圍：不重建人物、汽機車、自行車或車把。商店、建築、露台、陽傘、花槽、路牌、路緣、護欄、樹木與山景仍屬需比對的靜態場景。

## 比對方法

### 1. 建立影格與可見物清單

- 為每幀記錄 frame_id、PTS、reference image；參考圖保留原始尺寸。全片先以低密度圖集整理轉彎、路口、護欄起訖、森林轉換等事件，事件前後加密。
- 起點 0–48 秒優先以每秒 2 幀標註；轉頭、路口及遮擋變化區段再逐幀查看。最後的驗收仍輸出該段每一影格，不把抽樣當成全幀已驗收。
- 地標有穩定 ID，例如餐廳、左側旅館、右側木屋、石砌植栽島、個別大樹。記錄首次／最後出現時間、畫面位置、遮擋關係、形狀與材質證據、可信度。
- 人物、車輛、自行車、手臂、車把與原片 HUD／小地圖建立排除遮罩。被遮住的建築表面記為未知，從前後影格補證，不用任意補景當成已驗證。
- 小地圖可作路口與轉彎的輔助線索，但其畫面疊加不參與場景像素分數。

預定產物：影格索引、分段事件表、地標表、遮罩與起點標註圖集。

### 2. 校準相機，再校準道路

- 使用跨影格可追蹤的固定角點、道路邊界、立面垂直線與遠山線，估計相機位置、yaw/pitch/roll、視角與必要的鏡頭畸變。高度、路寬可作尺度先驗，但需標成估算。
- 保留原片起始側看與轉頭，不把「看向側邊」解讀為道路急轉。
- 建立 `video_pts → route_distance + camera_pose` 對應。現有 video_seconds/distance_m 僅作初始化，不能當作已校準結果。
- 道路沿位置與朝向證據局部修正，路口、標線、護欄起訖分開建模。單眼遮擋嚴重或證據不足區段保留不確定註記。
- 遠山用相同世界地形支援相鄰視點，不能只為某張圖調山或把照片當騎行場景背景。

驗收：跨多個時間點的固定地標投影能同時成立；相機軌跡連續，沒有以改鏡頭遮掩錯誤建築或道路。

### 3. 建立確定性的 Godot 對照輸出

- Luna 實作離線驗收模式：指定 reference PTS 即設定對應 camera pose，停止自動前進，等待完整渲染後截圖。輸出與原片同為 1920×1080。
- 相機取樣由影格索引驅動，不以實際執行 FPS 或等待秒數決定位置。固定隨機種子、資產版本、光照參數及可重現的動畫狀態。
- 自然畫面、線框／物件 ID／深度等診斷畫面分開輸出；診斷圖不能冒充最終視覺結果。
- 報表保留原片、Godot、50% 疊圖、邊界差異與缺失標註，支援按時間及地標查看；附資料／程式版本，修改後可重跑相同影格。

驗收：同一版本重跑同一影格不改變對位與物件布局；0、5、10、20、30、45 秒等錨點能一鍵定位。

### 4. 先修完整起點，再逐段擴張

先完成 0–10 秒的相機、餐廳街面和道路尺度樣板，再擴至 0–48 秒整個村鎮。依下列順序修正：

1. 道路寬度、坡度、路口、人行道、路緣和標線。
2. 主要建築的左右位置、尺寸、屋頂、樓層、開窗、陽台與店面，再補招牌、遮棚、露台等。
3. 對應的大樹與樹冠遮擋、花槽、護欄和擋土牆；森林依樹種形狀、冠層高度與透光程度建立，而非只調數量。
4. 山稜、谷地與遮擋層次。
5. 材質比例、色彩、粗糙度、曝光與陰影。幾何對位未達標前不以加材質細節代替。

起點通過後，依影片順序處理草甸、農舍、石牆彎道、森林、岩切、下段彎道與村落。每段交付可檢查的配對圖與差異清單，不以「有房子／有樹」當作一致。

### 5. 逐幀回歸與可讀報告

- 修正中的每段先跑密集關鍵影格，再跑該段所有原始影格；最後才跑全片 22,058 幀。可串流比對並保存問題影格，避免不必要地永久保留所有中間 PNG。
- 自動檢查道路／建築邊界、固定地標投影、山稜線、物件出現順序、漏物／多物與幀間跳變。
- 色彩或影像相似度僅作輔助。人物遮擋、雲、風、陰影和曝光差異可能影響像素；不以單一 SSIM 或總分宣稱重建一致。
- 護欄同時驗證沿道路切向、立柱直立，以及原片中的起訖位置、高度、遮擋和曲率。現有 dot=1 只涵蓋第一部分。
- 最終仍需人工查看關鍵錨點和連續播放，確認沒有「單張像、移動即穿幫」；未覆蓋幀、遮擋未知幀與失敗幀分開列出。

## 起點驗收門檻

以下是擬議門檻，需在相機校準樣板驗證可辨識性後固定，尚未測量或宣稱目前版本達標。

- **內容**：所有已標註的主要建築、路口、路緣、植栽島及大樹均存在，左右、前後與遮擋順序正確；無明顯多出的建物。關鍵漏物或錯路口直接判失敗，不被其他分數平均掉。
- **投影**：主要固定地標中位誤差目標 ≤ 畫面寬度 1%，95 百分位 ≤ 2%；山稜垂直誤差目標 ≤ 畫面高度 2%。使用原始相機校準投影，不用整張非剛性扭曲後的圖作弊。
- **道路與樹木**：道路邊界／路口形狀和樹冠遮擋分區量測，閾值在樣板中訂定；不得以全圖平均分掩蓋近景誤差。
- **連續性與觀感**：相鄰視點不跳動、不漂浮、不穿模；建築可辨識、樹木不是明顯紙片／重複錐體，材質無顯眼拉伸或顆粒閃爍。
- **覆蓋**：該段每個參考影格都有配對或明確的不可判定原因；關鍵錨點有逐項人工結論。報告標記通過、待修與未知，不能寫成「百分之百完全一致」。

## 限制與應對

- 單眼影片不能保證唯一的真實 3D 尺度與背面內容；採多影格一致約束，未知內容明示，必要時再找額外地理資料。
- 起點動態遮擋多，必須從前後影格補證；遮罩排除的區域不能列為已比對通過。
- 現有估算路線可能需大幅修正，應版本化保留現況，先做短段樣板；不預承諾只靠小幅調整即可達標。
- 執行效率與畫質分開驗收。相符後再做 LOD 與效能取捨，並以相同對照影格檢查退化。
