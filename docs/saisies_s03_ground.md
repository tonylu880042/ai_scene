# S03 草坡與地表材質

本輪只處理草坡顏色、灰白裸露區與生硬材質交界。root分析／原生驗收、Luna實作，以約80%人工視覺目標為止。

## 完成內容

五個地表物件保留原始材質的複製品，再加S03專用遮罩材質：主烘焙地形、S01RidgeTerrainOverlay、S01ForestFloorCover、兩個GrassSlope。低飽和橄欖綠共用世界座標平滑雜訊，避免不同補面各用一套深淺色。草坡區域沿路900m／橫向700m，邊緣140m漸退；相對S03相機高度300–450m向上漸退，保留遠方高山。依實際相機世界座標，離S03視點340–440m漸退，避免S01/S02被重新改色。

第一版過暗且覆蓋範圍太小；第二版陽光面偏鮮黃綠，均保留中間結果。最終以較柔和的綠色完成原生主圖、2m側移與咖啡館近景驗收。仍能看到部分地形條帶與平滑拉伸感；本輪不變更地形、樹形或山稜，完整S03未判通過。下一項為纜線、空吊椅及右支柱比例。
