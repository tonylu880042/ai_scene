# S03 咖啡館沉入路面修正

使用者指出R17左側咖啡館像沉入道路。本輪只處理這一項，root分析／原生驗收，Luna實作。S01/S02已接受，R17路口與護欄保留。

## 原因與修正

原咖啡館位於station970m、lateral12m，處於展寬路口的範圍。先前只檢查烘焙地形接觸，漏掉可見新鋪面與屋身相交。從實際屋身四角及入口採樣R17 pavement三角形，最深穿入約1.373m。移至1000m/lateral20m的第一候選被後方公寓擋住，原生退修並保存。

最終保留原XZ位置及basis，整個屋身／屋頂／門窗抬高1.545m。地坪依實際鋪面最高footprint樣點加0.12m，不以相機旋轉掩飾。屋身四角及入口5個獨立檢查點全部高於鋪面，最小0.173m。重建基座、封閉的平台支撐、門前2m寬12級實體台階（約0.162m高、0.30m深），接至實際路面。

## 驗收

固定主視角station930m/FOV77°，1920×1080，前後相機位置相同。Metal原生主圖、實際2m側移圖、60°入口近景完成；入口近景隨屋身高度移動，不能當同一世界相機的比對。最終日誌沒有場景／腳本錯誤。272個來源、6個資產雜湊確認；既有R17的267個來源完全一致，沒有更動既有路口、護欄、S01/S02。

本項下沉問題完成並保留，完整S03未判通過；咖啡館原片構圖／背景公寓、材質招牌與其餘景物仍有差異，不追求本輪100%。未量測效能或重跑全程。
