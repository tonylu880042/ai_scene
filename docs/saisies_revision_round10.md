# Saisies 下一輪退修規格：近路景物與林緣

狀態：2026-10-18 已交付三位既有 Luna 執行。以下為實作與驗收規格；完成項目另記，不能視為已通過。維持 Luna 開發、root 逐幀驗收。原片18個固定影格不變，人物／車輛仍排除。

## 優先順序

1. 先以相鄰影片影格、明確彎道／護牆端點校對 S08、S13 的道路位置及相機投影；HUD 高度只能作交叉參考，不能單獨當 GPS。S08 目前 station5143.26 與 HUD 高度候選5408 保持分開，不擅自改正式錨點。S13 的 RGE 約991m雖與HUD接近，仍不能證明彎道／相機對準。
2. 建立原片可辨識的近路結構：S08 右側低實體護牆，S09 左側低石擋牆，S13 左側天然岩壁。不能用高光滑地形平面代替它們，也不能照舊 v2 anchor 生搬到地理座標。
3. 在各幀有證據的道路區間調整林緣、樹冠及林下層；特別移除 S09 開闊左草坡上不符原片的近路針葉樹。OSM 舊林區只能作候選範圍，不能凌駕原片。

## 每幀文字與對照

### S08／315s

以 acceptance JSON 的原始 `reference_image` 為準（此標題僅標時間，實際幀序號不得手抄替換）。原片是森林包覆的下坡道路，兩側近距離枝葉讓上緣只剩狹長天空開口。左側是短草土切坡，裸露部分只在近路下緣；右側低實體護牆沿道路延伸，後方為闊葉立幹與濃密冠層。中央遠山由樹縫露出。第九輪有更近樹冠與樹影，但仍看見大片谷地、左坡過高且過於光滑，護牆未建立。

驗收看：天空／谷地的露出區域、牆頂投影及端點、路面白線曲率、左坡可見高度、樹冠前後重疊。不可用把樹等距放滿兩旁來通過。

### S09／330s

原片左側是貼路低石砌擋牆，其上接開闊綠草坡，較高處才有零散針闊葉樹與房屋。道路明顯右彎；右側金屬欄後樹木濃密、貼近視線。第九輪護欄相對柏油高度已修正，但左側仍缺石牆，新增的貼路高針葉樹侵占原片草坡開口，應退修。

驗收看：石牆高度與石塊尺度、草坡開闊範圍、右彎遮擋、右側樹冠與護欄前後關係。不得整片刪林或全線換樹種；限制在有原片證據的局部區間。

### S13／630s

原片左側岩壁緊貼道路並沿左彎繞出視線，有不規則凸出、裂面、局部植被與防護網線條。右側闊葉林壓近路緣，樹冠遮住大部分谷地，遠方山層只從中上方開口露出。第九輪恢復一些冠層及路面樹影，但岩壁仍缺、道路投影偏直、谷地太開放，樹木外形與間隔重複。

驗收看：岩角輪廓及其與左彎遮擋、右冠層封閉程度、遠山露出位置、路緣和土草交接。岩壁使用真正不規則三維幾何，不再採長平牆或懸浮薄片。

## 接地與近路斷面

第九輪 GPU 驗證的是樹木定位點與實際 terrain triangle 相符；並未證明整個外張樹根都埋入坡面。圖片仍可見部分根部邊緣像懸空。下一版須檢查旋轉／縮放後實際可見根部 footprint，依局部地面埋入或排除不適合生樹的陡岩，不能只放寬根點 assertion。

近路仍有過寬的平整淡色帶：現有8m clearance core及4m roadbed skirt會吞掉細緻路緣。應先做一個小區的道路邊緣／土草／短坡截面，再驗實際三角形不遮柏油及無懸空路邊。禁止把整個山谷再壓平。

## 分工建議與停止條件

- Camera Luna：先做相鄰影格與道路投影診斷，提出可辨識地標錨點；未確認前不改固定驗收時間。
- Terrain Luna：獨立近路結構模組與局部路緣斷面，不更動共用 datum／道路 XY。
- Forest Luna：依 root 指定的局部林緣修正、林下層與實際根部 footprint，保留道路／建物排除和 GPU instance 證據。
- root：依同一文字與原片圖驗收，保留拒收方案；不能以量化指標或技術 PASS 抹掉圖片差異。

先完成三個局部段落的可檢查畫面，再延伸全線。新增結構不得遮住車道、伸入支路、在天空留下洞或產生不合理垂直矩形端面。未符合原片者維持退修，既有 v2 烘焙不由實驗版覆寫。

本輪先實作 S13 獨立岩壁、可見樹根 footprint 接地與 S09 局部林緣修正；Camera Luna 先交相鄰影格／曲率診斷，不直接改正式錨點。S08護牆後續再處理，避免一次擴散多個未驗證變因。

時間更正：S09固定原片為330秒（frame7912），前輪文字曾誤寫360秒，已以acceptance JSON校正；局部林緣修正應以330秒為中心，不能套到另一段路。

### Root攔截：彎道方向診斷錯誤

root在原生試拍發現10244m候選的彎向與原片不符，回查診斷工具的`atan2(-tangent.x,-tangent.z)`與左右分類：朝-Z走向-X的左轉會得到正角，舊工具卻把負角標為左轉。10279m的負曲率極值不可當左彎依據，因此10244m候選撤回驗收資格，待正確方向的原生試拍後另記決策。岩壁／森林技術成果可保留，但不能以舊錯誤診斷支持時間錨點。舊probe與診斷保留為被拒方案。
